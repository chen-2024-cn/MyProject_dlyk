1. 交易阶段流转：创建交易(01新建) -> 阶段跟进 -> 成交(08成交)；成交后金额计入业绩。
2. 线索转化：线索录入 -> 线索跟进(添加跟进记录) -> 转为客户 -> 建立交易。
3. 客户数据权限：普通用户只能查看与操作本人名下的线索/客户/交易，管理员可查看全部。
4. 交易提醒：交易设置下次联系时间后，系统会在临近时提示跟进，建议保持每日查看。
5. 字典管理：阶段、来源、称谓等下拉选项统一由字典维护，如需新增请联系管理员。
6. 数据安全：账号密码加密存储，单设备登录互斥，异地登录当前设备会被顶下线。
