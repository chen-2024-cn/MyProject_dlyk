# 动力云课示范 项目介绍

## 一、项目概述

**动力云课示范**（dlyk）是一套面向销售团队的 **CRM（客户关系管理）系统**，核心业务围绕销售全流程展开：从线索获取、线索跟进、转化为客户，到最终达成交易，并提供营销活动管理与数据统计分析功能。

项目采用前后端分离架构，前端为 Vue 3 + Vite 单页应用，后端为 Spring Boot 3 RESTful API 服务。

- **版本**: 0.0.1-SNAPSHOT
- **运行环境**: Node.js `^20.19.0 || >=22.12.0`，Java 21

## 四、功能模块

### 1. 用户认证与权限

- **JWT 登录**: 账号密码登录，支持"记住我"（token 持久化至 localStorage），以及免登录令牌验证
- **权限控制**: 精细到操作级别的权限字符串（如 `user:add`、`clue:delete`），前端通过 `v-hasPermission` 指令控制按钮显隐，后端通过 Spring Security 拦截验证
- **个人中心**: 个人信息编辑、密码修改、权限列表查看

### 2. 仪表盘与数据统计

- **概览卡片**: 有效/总活动数、总线索数、总客户数、成功/总交易金额
- **ECharts 图表**:
  - 销售漏斗图（线索 → 客户 → 交易转化）
  - 线索来源饼图（广告、渠道、转介绍等）
  - 月度趋势折线图（线索数、客户数、交易额）

### 3. 线索管理

- 线索 CRUD，支持搜索与筛选
- **批量导入**: 通过 EasyExcel 拖拽上传 Excel 文件批量导入线索
- **批量删除**
- 线索详情页展示关联的字典数据（称呼、贷款需求、意向状态等）
- **跟踪记录**: 每条线索可添加多条跟进记录（跟进内容 + 跟进方式）

### 4. 客户管理

- 客户列表（由线索转化而来），支持搜索与筛选
- 客户详情页展示完整信息及关联的 **交易记录**
- **Excel 导出**: 支持全量导出和选中导出

### 5. 交易管理

- 交易 CRUD，支持按客户、金额筛选
- **阶段管理**: 交易可推进/回退阶段（如：初步接触 → 需求分析 → 报价 → 谈判 → 成交）
- **阶段历史**: 查看交易阶段变更的完整历史
- **跟踪记录**: 与线索类似的跟进/备注功能

### 6. 营销活动管理

- 营销活动 CRUD，多条件搜索（负责人、名称、日期范围、预算等）
- **备注系统**: 活动可关联多条备注，支持增删改

### 7. 产品管理

- 产品 CRUD（名称、指导价区间、报价、在售/下架状态）

### 8. 字典管理

- 双栏布局：字典类型（左） + 字典值（右）
- CRUD 操作，为其他模块提供数据字典支持（称呼、意向状态、线索来源等）

### 9. 系统配置

- 可编辑系统名称、标题、版本、描述、站点地址、Logo、联系方式
- 系统开关 + 关闭提示信息

### 10. AI 对话

- 对接 DeepSeek API 的聊天接口，提供智能辅助功能

## 六、后端分层架构

```
Controller (web/)          ← REST API 端点，接收 HTTP 请求
    ↓
Manager (manager/)         ← 业务编排（如线索转客户、统计分析）
    ↓
Service (service/)         ← 核心业务逻辑
    ↓
Mapper (mapper/)           ← MyBatis 数据访问，XML 映射文件
    ↓
Database (MySQL + Redis)   ← 数据持久化与缓存
```

- **统一响应**: 所有接口使用 `R` 对象包装，包含 `code`、`data`、`msg` 字段
- **身份验证**: Spring Security + JWT 无状态会话，Token 通过 `Authorization` 请求头传递
- **数据缓存**: 静态 `HashMap` 内存缓存字典、产品、活动数据，每 3 分钟定时刷新

## 八、快速启动

### 环境要求

- Node.js 20.19+ 或 22.12+
- Java 21
- MySQL 8.x + Redis

### 后端

```bash
cd server
# 确保 application.yml 中的数据库和 Redis 连接配置正确
mvn spring-boot:run
```

默认端口：`8089`

### 前端

```bash
cd front
npm install
npm run dev
```

默认端口：Vite 开发服务器端口（通常 `5173`）

## 九、核心业务流程

```
线索（Clue）
  │  导入 / 手动创建
  │  添加跟踪记录
  │
  └──→ 转化为 客户（Customer）
            │
            │  关联 产品（Product）
            │  关联 交易（Tran）
            │
            └──→ 交易阶段推进
                      │
                      ├── 初步接触
                      ├── 需求分析
                      ├── 报价
                      ├── 谈判
                      └── 成交
```
